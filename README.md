# isle bakery — 데모 샘플 (이피웹)

성북 소재 크래프트 베이커리 isle.bakery 가상 시안. 인스타그램(@isle.bakery) 공개 자료 기반.

- 단일 파일 `index.html` (인라인 CSS/JS), 모바일 우선.
- 폰트: Shantell Sans + Caveat (Google Fonts CDN), Pretendard(다이내믹 서브셋). ⚠️ 납품 시 self-host 전환.
- 브러시 로고 `logo-isle.png`: 사장님 플리마켓 포스터에서 추출한 실제 워드마크.
- 배포: Cloudflare Workers 정적 자산. 데모 도메인 `isle-bakery-sample.lgt3232.workers.dev`.

## 확인·교체 대기
- 정확한 주소·지도(현재 "성북구, 서울"만 표기)
- 전화번호(미확보)
- 메뉴 실가격·최신 구성(시즌 변동)
- 콜로소 강사=대표 여부 최종 확인(현재 링크만)
